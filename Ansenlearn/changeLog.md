# 协同修改日志（Change Log）

> 本文件用于多个协同工作空间同时改动本项目代码时，记录每次修改、同步改动状态，避免盲改覆盖。

## 使用机制（规则）

1. **修改者名单**：当前两名协作者——**主线** 与 **支线-1**。
2. **改动前必读**：每次动手改代码前，先读本文件的「表格内容」，检查**自己那一列**是否有「已读」标记。
3. **已读标记**：表格中「主线」「支线-1」各占一列。**新增条目时，只在修改者自己那一列打「已读」，其他协作者的列留空。判断时只看自己那一列：没有「已读」（即空）就表示未读。**
4. **修改前先登记**：协作者动手改代码前，先在表格**尾部追加一条**改动记录（自己那一列打「已读」，其他列留空），再开始改。
5. **本文件只记表格**：本文件只保留「表格内容」（每条改动的序号/时间/修改者/文件/概要/已读状态）。
6. **概述另存**：每次改动的「修改概述」（详细说明）写入 `Ansenlearn/improvement.md`，**使用与表格相同的编号**一一对应。
7. **一切尾部追加**：表格内容与 `improvement.md` 的概述，一律尾部追加，不覆盖、不重排。
